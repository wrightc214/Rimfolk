# Rimfolk

Working project name; published mod name TBD. A RimWorld 1.7 single-pawn, multigenerational life simulator in an autonomous permanent settlement.

Development begins by proving an AI colony manager can **sustain**, **expand**, and **establish** a settlement without player intervention. The initial playable scenario is an established settlement, not an Odyssey gravship.

Requires Biotech, Ideology and Royalty. No official Combat Extended support. See docs for design, roadmap, decisions and Observer diagnostics.

GitHub is the source of truth. Use scoped issues, feature branches and pull requests. Critically evaluate design decisions rather than automatically agreeing.
